# Skills

Agent skills by Emman Nelson. They follow the [Agent Skills specification](https://agentskills.io/specification), so they work in Claude Code, Codex, Cursor, OpenCode, and other agent harnesses that read the format.

## Installation

### Via skills.sh

```bash
npx skills add eyounelson/skills
```

### Via Claude Code

```
/plugin marketplace add eyounelson/skills
/plugin install content-writing@eyounelson-skills
```

## What's Included

| Skill | Description |
|-------|-------------|
| `deslop` | Write and edit content without the tells in Wikipedia's [Signs of AI writing](https://en.wikipedia.org/wiki/Wikipedia:Signs_of_AI_writing) |

## Keeping Up to Date

### skills.sh

```bash
npx skills update
```

### Claude Code

```
/plugin marketplace update eyounelson-skills
```
